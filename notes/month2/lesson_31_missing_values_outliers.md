## 1. Что означает пропущенное значение

`NaN`, `None` и `<NA>` могут использоваться как маркеры отсутствующих данных.
Их инженерный смысл — «значение неизвестно». Это не то же самое, что известный
ноль, пустая строка или подтверждённый `False`.

Пропуски могут появляться из-за потери пакета датчика, ошибки преобразования,
необязательного поля или отсутствия совпадения после `left merge`.

Строка `"None"` — обычный текст. Она не распознаётся pandas как пропуск:

```python
"None" is not None
```

Когда числовой столбец содержит обычный `NaN`, pandas может перевести целые
значения из `int64` в `float64`, потому что обычный NumPy `int64` не способен
хранить `NaN`.

## 2. Поиск и подсчёт пропусков

```python
missing_by_column = readings.isna().sum()
missing_mask = readings.isna().any(axis=1)
rows_with_missing = readings.loc[missing_mask]
```

Механика:

1. `isna()` создаёт булеву таблицу того же размера;
2. `sum()` по умолчанию схлопывает строки и считает `True` по столбцам;
3. `any(axis=1)` проверяет каждую строку и возвращает `True`, если хотя бы одна
   ячейка отсутствует;
4. булева маска выбирает проблемные строки через `.loc`.

Для исходной таблицы были получены три строки с пропусками: `CNC-02`, `CNC-03`
и `CNC-05`.

## 3. Как работает `dropna(subset=...)`

```python
temperature_available = readings.dropna(subset=["temperature"])
```

`dropna()` удаляет строки. Параметр `subset` указывает, какие столбцы проверять
при принятии решения об удалении строки.

- `dropna()` — удалить строку при пропуске в любом столбце;
- `dropna(subset=["temperature"])` — удалить строку только при отсутствующей
  температуре;
- `dropna(subset=["temperature", "rpm"])` — удалить строку, если отсутствует
  хотя бы одно из двух значений при стандартном `how="any"`.

Метод по умолчанию возвращает новый DataFrame. Исходные данные не изменяются,
если результат сохранён в другой переменной.

## 4. Заполнение пропуска и происхождение данных

Перед заполнением создана независимая копия:

```python
cleaned_data = readings.copy()
```

Затем сохранён флаг происхождения значения:

```python
cleaned_data["temperature_was_missing"] = readings["temperature"].isna()
```

Только после этого пропуск температуры заполнен медианой через `fillna()`.
Флаг позволяет отличить измерение датчика от значения, восстановленного
алгоритмом. Это часть **data lineage** — происхождения данных.

Пропуски `rpm` и `is_running` намеренно не заменены на `0` и `False`, потому что
для такого решения не было подтверждённого инженерного правила. Неизвестный
статус нельзя выдавать за остановленный станок.

## 5. Среднее, медиана и влияние выброса

Для значений:

```text
72.0, 91.5, 350.0, 74.0
```

получено:

```text
mean   = 146.875
median = 82.75
```

Значение `350.0` резко увеличило среднее. Медиана оказалась устойчивее, поэтому
она выбрана для временного заполнения пропущенной температуры.

Это не доказывает, что медиана всегда является правильной заменой. Стратегия
зависит от физики процесса, распределения данных и назначения анализа.

## 6. Выброс и инженерный порог

**Outlier** — значение, заметно отличающееся от основной массы. Оно может быть
ошибкой датчика, аварией или реальным редким событием.

В уроке использован предметный порог:

```python
cleaned_data["temperature_outlier"] = (
    cleaned_data["temperature"] > 120
)
```

Строка `CNC-04` с температурой `350.0` не удалена, а помещена в диагностический
отчёт. Решение об удалении принимается только после выяснения причины.

Флаг нужно рассчитывать по тому DataFrame, в который он записывается. Расчёт по
исходной таблице после заполнения очищенной мог бы создать несогласованные
результаты.

## 7. Инженерное задание — отчёт качества

Собран `quality_report` с пятью вычисляемыми метриками:

```text
total_rows              = 5
rows_with_missing       = 3
temperature_filled      = 1
temperature_outliers    = 1
unresolved_missing_cells = 2
```

Булевы столбцы можно суммировать, потому что `True` соответствует `1`, а
`False` — `0`.

Словарь с одиночными скалярными значениями нельзя передать как
`pd.DataFrame(quality_report)` без указания индекса. Для одной строки отчёта
использован список из одной записи:

```python
quality_report_frame = pd.DataFrame([quality_report])
```

Форма результата: `(1, 5)` — одна проверка и пять показателей.

## Ошибки и уточнения

- Первоначально числа, `True`, `False` и `None` были записаны в кавычках и стали
  строками. Исправлено различие между литералами Python и текстом.
- `subset` сначала воспринимался как выбор удаляемого столбца. Уточнено: он
  задаёт столбцы для проверки, а удаляется строка целиком.
- Флаг выброса сначала вычислялся по исходной таблице и записывался в очищенную.
  Источник исправлен на `cleaned_data`.

- Попытка `pd.DataFrame(quality_report)` завершилась `ValueError`, потому что
  pandas не мог определить число строк по набору скаляров. Словарь обёрнут в
  список как одна запись.
