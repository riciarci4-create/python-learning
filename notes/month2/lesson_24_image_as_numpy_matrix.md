## Контекстный менеджер

Изображение открывается так:

```python
with Image.open(image_path) as image:
```

Последовательность:

1. `Image.open(image_path)` создаёт объект изображения;
2. `as image` сохраняет объект в обычную переменную;
3. блок с отступом работает с открытым ресурсом;
4. `with` закрывает файл при выходе, в том числе при исключении.

Это надёжнее ручного `image.close()`, который может не выполниться после ошибки.

## Изображение как массив

Pillow сообщил:

```text
size = (200, 100)
mode = RGB
```

Pillow использует порядок `(width, height)`. NumPy хранит RGB-изображение как:

```text
(height, width, channels)
```

После:

```python
image_array = np.array(image)
```

получены:

```text
shape = (100, 200, 3)
ndim = 3
dtype = uint8
```

`uint8` хранит целые значения без знака в диапазоне `0–255`.

## Индексация пикселя

Пиксель выбирается в порядке:

```python
image_array[y, x]
```

Первый индекс — строка/высота, второй — столбец/ширина. Верхний левый и
центральный пиксели однотонного красного изображения:

```text
[255, 0, 0]
```

Это максимальный красный канал и нулевые зелёный и синий каналы.

## Grayscale

Метод:

```python
image.convert("L")
```

создаёт новое изображение в режиме яркости `L`. После преобразования:

```text
shape = (100, 200)
ndim = 2
```

Ось каналов исчезает. Красный пиксель стал значением яркости `76`, потому что
grayscale использует взвешенное сочетание RGB-каналов, а не простую сумму.

## Matplotlib

RGB-массив отображён через:

```python
plt.imshow(image_array)
plt.title("Тестовое изображение")
plt.axis("off")
plt.show()
```

- `imshow()` подготавливает изображение;
- `title()` задаёт заголовок;
- `axis("off")` скрывает координатные оси;
- `show()` отображает фигуру.

## Профиль яркости

Для grayscale-массива формы `(100, 200)`:

```python
column_brightness = grayscale_array.mean(axis=0)
```

схлопывает 100 строк и возвращает одномерный профиль формы `(200,)` — по одному
среднему значению на каждый столбец.

У однотонного изображения минимум и максимум профиля равны `76.0`, поэтому
линейный график горизонтален.

График построен через:

```python
plt.plot(column_brightness)
```

При передаче одного массива Matplotlib использует индексы элементов как
координаты X.

## Инженерное задание: тёмная полоса

Независимая копия создана через:

```python
defect_image = grayscale_array.copy()
```

Без `.copy()` две переменные ссылались бы на один массив, и изменение
дефектной версии повредило бы исходные данные.

Вертикальная полоса:

```python
defect_image[:, 90:110] = 0
```

изменяет все строки и столбцы `90–109`. Исходный центральный пиксель остался
`76`, а пиксель копии стал `0`.

После:

```python
defect_profile = defect_image.mean(axis=0)
```

на графике появился провал яркости в диапазоне дефектных столбцов.

Важно: текущая программа визуализирует отклонение, но ещё не классифицирует его
автоматически. Для автоматического обнаружения понадобится порог или другой
алгоритм принятия решения.

## Math Core

- RGB-изображение — трёхмерный тензор `(height, width, channels)`.
- Grayscale-изображение — матрица `(height, width)`.
- Яркость grayscale-пикселя — взвешенная комбинация RGB-каналов.
- `mean(axis=0)` выполняет свёртку высоты и создаёт профиль по ширине.
- Контраст дефекта можно оценивать разностью нормальной и аномальной яркости.

Эти идеи будут разобраны глубже в отдельном Math Core перед экзаменом недели 5.
