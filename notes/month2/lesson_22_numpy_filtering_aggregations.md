# Урок 22 — фильтрация и агрегирование NumPy

**Дата:** 2026-07-24  
**Статус:** `Retained`

**Отсроченная проверка:** 2026-07-27 — без конспекта восстановлена цепочка от
выбора температурного столбца до фильтрации полных строк исходной матрицы.

## Цель

Научиться выбирать элементы и полные строки массива по условию, получать
сводные показатели и безопасно обрабатывать пустую выборку.

После урока пользователь умеет:

- строить булеву маску сравнением массива с порогом;
- фильтровать одномерный массив;
- фильтровать полные строки двумерной матрицы по одному столбцу;
- вычислять `min`, `max`, `mean` и количество срабатываний;
- проверять выборку перед вычислением среднего.

## Основная теория

### Булева маска

Сравнение массива с числом выполняется поэлементно:

```python
temperatures = np.array([68, 92, 85, 97, 74])
overheat_mask = temperatures > 85
```

Результат:

```text
[False, True, False, True, False]
```

`True` отмечает позицию, прошедшую условие. При строгом сравнении `>` значение,
равное порогу, не проходит. Для включения границы нужен оператор `>=`.

### Фильтрация

Булева маска используется как индекс:

```python
overheat_temperatures = temperatures[overheat_mask]
```

Результат:

```text
[92, 97]
```

Квадратные скобки выполняют индексацию. Круглые скобки попытались бы вызвать
массив как функцию и привели бы к `TypeError`, потому что `ndarray` не является
вызываемым объектом.

### Агрегирование

Агрегирование сворачивает набор значений в сводный показатель:

```python
temperatures.min()
temperatures.max()
temperatures.mean()
```

Для исходного массива получены:

- минимум — `68`;
- максимум — `97`;
- среднее — `83.2`.

Среднее отфильтрованной выборки `[92, 97]` равно `94.5`. Метод всегда работает
с тем массивом, у которого он вызван.

### Фильтрация полных строк

В матрице:

```text
[номер станка, температура, обороты]
```

температурный столбец выбирается выражением:

```python
machine_temperatures = machine_data[:, 1]
```

После построения маски её применение к `machine_data` выбирает полные строки:

```python
critical_mask = machine_temperatures > 85
critical_machines = machine_data[critical_mask]
```

Результат содержит все параметры станков 2 и 4, а не только температуры.

### Подсчёт срабатываний

В арифметическом контексте `True` соответствует `1`, а `False` — `0`.
Поэтому:

```python
critical_count = critical_mask.sum()
```

возвращает количество строк, прошедших условие.

### Пустая выборка

При пороге `100` ни одна строка не проходит. Массив `critical_machines` имеет
форму `(0, 3)`: строк нет, но структура из трёх столбцов сохранена.

Среднее пустого массива обычно не вызывает исключение. NumPy выдаёт
предупреждение и возвращает `nan`. Поэтому перед вычислением используется
защитное условие:

```python
if critical_count > 0:
    ...
else:
    ...
```

Это не позволяет нечисловому результату незаметно попасть в отчёт или
дальнейший ML-пайплайн.

## Инженерное применение

Реализован конвейер:

```text
матрица станков
→ температурный столбец
→ маска превышения порога
→ полные строки критических станков
→ количество и средняя критическая температура
```

Такой шаблон применяется для поиска выхода измерений за допуск, очистки данных,
формирования аварийных отчётов и подготовки признаков для ML.

## Проверенные граничные случаи

- температура, равная `85`, не проходит строгое условие `> 85`;
- порог `100` создаёт полностью ложную маску;
- пустая выборка сохраняет форму `(0, 3)`;
- защитное условие предотвращает вычисление среднего пустой выборки;
- после теста рабочий порог возвращён на `85`.

## Исправленные неточности понимания

- Значение внутри круглых скобок было названо аргументом без уточнения, что сами
  скобки означают вызов объекта. Для массива здесь нужны квадратные скобки.
- Сначала были названы только температуры `92` и `97`, хотя маска применялась
  к двумерной матрице и возвращала полные строки.
- Возможный результат пустого среднего был назван ошибкой. Уточнено: обычно это
  предупреждение и `nan`, а не остановка программы исключением.
- Переменная `critical_machine` переименована в `critical_machines`, потому что
  содержит несколько строк.

## Math Core

- Среднее арифметическое: сумма значений, делённая на их количество.
- Сумма булевой маски равна числу выполненных условий.
- Среднее чувствительно к выбросам: значение `970` вместо `97` резко сдвигает
  показатель и делает его ненадёжным описанием обычной температуры.
- Порог превращает непрерывное измерение в инженерные категории: допустимо /
  критично.

## English Core

- **boolean mask** — булева маска;
- **filtering** — фильтрация;
- **aggregation** — агрегирование;
- **threshold** — порог;
- **edge case** — граничный случай;
- **outlier** — выброс;
- **data pipeline** — конвейер обработки данных;
- **Not a Number (`nan`)** — нечисловой результат.
