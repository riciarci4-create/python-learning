## Скаляр, вектор и матрица

**Scalar — скаляр**: одно число, например температура одного станка.

**Vector — вектор**: упорядоченный одномерный набор чисел, например температуры
нескольких станков в один момент.

**Matrix — матрица**: двумерная таблица. Если строки соответствуют станкам, а
столбцы — моментам измерения, форма `(5, 3)` означает пять станков и три момента.

При агрегировании указанная ось исчезает:

- `mean(axis=0)` схлопывает строки и возвращает среднее каждого столбца;
- `mean(axis=1)` схлопывает столбцы и возвращает среднее каждой строки.

Физический смысл определяется не самим числом, а договорённостью о том, что
означают строки, столбцы и единицы измерения.

## Среднее, медиана и диапазон

Среднее арифметическое:

```text
mean = (x1 + x2 + ... + xn) / n
```

Медиана — центральное значение после сортировки. При чётном количестве
наблюдений берётся среднее двух центральных значений.

Диапазон:

```text
range = max(x) - min(x)
```

Для `[70, 72, 74, 73, 71, 98]` получено:

```text
mean   = 76.33
median = 72.5
range  = 28
```

Значение `98` сдвигает среднее, поэтому медиана лучше описывает обычный уровень
основной группы. При этом крайнее значение нельзя автоматически удалить: оно
может быть реальным перегревом, а не ошибкой датчика.

## Дисперсия и стандартное отклонение

Отклонение отдельного значения:

```text
deviation = value - mean
```

Дисперсия полного набора:

```text
variance = sum((value - mean) ** 2) / n
```

Стандартное отклонение:

```text
standard_deviation = sqrt(variance)
```

Для `[70, 72, 74]`:

```text
mean = 72
deviations = [-2, 0, 2]
squared deviations = [4, 0, 4]
variance = 8 / 3 = 2.67
standard deviation ≈ 1.63
```

Дисперсия измеряется в квадратных единицах, а стандартное отклонение — снова в
исходной единице. Поэтому стандартное отклонение проще интерпретировать как
характерный масштаб разброса, но оно не является максимальным отклонением.

## RGB как вектор и взвешенная сумма

RGB-пиксель можно представить вектором `[R, G, B]`. Приближённая яркость:

```text
L = 0.299 * R + 0.587 * G + 0.114 * B
```

Это скалярное произведение RGB-вектора и вектора весов. Каналы имеют разные
веса, потому что человеческое зрение воспринимает их яркость неодинаково.

Для `[255, 0, 0]` получается `76.245`, то есть примерно `76`. Для чистого
зелёного пикселя получается `149.685`, то есть примерно `150`.

## Z-score

Стандартизированное отклонение:

```text
z = (candidate - baseline_mean) / baseline_std
```

- `z = 0` — значение совпадает со средним;
- положительный знак — значение выше среднего;
- отрицательный знак — значение ниже среднего;
- `abs(z)` показывает расстояние до среднего в стандартных отклонениях.

Для яркости `100`, среднего `150` и стандартного отклонения `10`:

```text
z = (100 - 150) / 10 = -5
```

Отрицательный знак означает более тёмный участок, потому что в grayscale меньшее
значение соответствует меньшей яркости.

Порог вроде `abs(z) > 3` является инженерным правилом, а не универсальным
законом. Его выбирают по данным, цене ложной тревоги и цене пропущенного дефекта.

## Загрязнённая базовая линия

Если аномальное значение включить в данные нормального режима, оно изменит и
среднее, и стандартное отклонение.

Для полного массива с `98`:

```text
mean ≈ 76.33
std ≈ 9.78
z(98) ≈ 2.22
```

Для чистой базы `[70, 72, 74, 73, 71]`:

```text
mean = 72
std ≈ 1.41
z(98) ≈ 18.38
```

Инженерный вывод: эталонные статистики должны рассчитываться по подтверждённому
нормальному режиму. Иначе аномалия частично маскирует сама себя.

## Функция и контракт

Создана функция:

```python
def calculate_z_score(baseline_values, candidate_value):
    if baseline_values.size == 0:
        return None
    mean_value = baseline_values.mean()
    std_value = baseline_values.std()
    if std_value == 0:
        return None
    return (candidate_value - mean_value) / std_value
```

Контракт:

- нормальная непустая база с ненулевым разбросом возвращает `float`;
- пустая база возвращает `None` до вызова `.mean()`;
- постоянная база возвращает `None`, потому что деление на `std = 0` невозможно;
- функция не печатает результат и может повторно использоваться вызывающим кодом.

Проверены три сценария:

```text
нормальная база  -> 18.384776310850235
постоянная база -> None
пустая база     -> None
```

## Ошибки и причины

- `dtype = float` отдельно от `np.array()` не меняет тип массива. `dtype=float`
  должен быть аргументом при создании массива.
- Присваивание `temperatures.dtype = float` пытается изменить описание памяти,
  устарело в NumPy 2.5 и не является корректным преобразованием значений.
- `.mean` без скобок обозначает метод, а `.mean()` выполняет вычисление.
- `.size` — атрибут, поэтому запись `.size()` ошибочна.
- `std.value` означает атрибут `value` несуществующего объекта `std`; имя обычной
  переменной записывается как `std_value`.
- В первых тестовых выводах были напечатаны исходные массивы вместо переменных с
  результатами функции. Входные данные и результат обработки нужно различать.

## Math Core

- Размерность и оси задают структуру данных и физический смысл агрегаций.
- Среднее описывает центр, но чувствительно к выбросам.
- Медиана устойчивее к единичным крайним значениям.
- Диапазон показывает полный размах.
- Стандартное отклонение показывает характерный масштаб разброса.
- `z-score` переводит абсолютное отклонение в количество стандартных отклонений.
- Статистический детектор надёжен только относительно корректной нормальной базы.
