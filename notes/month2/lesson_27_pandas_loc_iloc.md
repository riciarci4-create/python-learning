# Урок 27 — выбор данных через loc и iloc

## Цель урока

Научиться точно выбирать столбцы, строки и отдельные ячейки `DataFrame`,
различая выбор по меткам и по целочисленным позициям.

После урока пользователь умеет:

- читать `Index` и `RangeIndex`;
- выбирать один столбец как `Series` и несколько как `DataFrame`;
- использовать `loc[строки, столбцы]`;
- использовать `iloc[позиции_строк, позиции_столбцов]`;
- учитывать разные правила правой границы среза;
- назначать инженерный идентификатор индексом через `set_index()`;
- проверять структуру результата через `type`, `ndim` и `shape`.

## Входная таблица

Повторно использован `machine_readings.csv` из урока 26. Путь построен
относительно Python-файла:

```python
lesson_dir = Path(__file__).resolve().parent
csv_path = lesson_dir / "machine_readings.csv"
readings = pd.read_csv(csv_path)
```

Исходная форма — `(4, 4)`. Индекс:

```text
RangeIndex(start=0, stop=4, step=1)
```

Он создаёт метки `0, 1, 2, 3`. Правая граница `4` не входит в диапазон.

## Выбор одного и нескольких столбцов

Один столбец:

```python
only_temperature = readings["temperature"]
```

Результат — `Series` формы `(4,)`.

Несколько столбцов:

```python
machine_id_and_rpm = readings[["machine_id", "rpm"]]
```

Результат — `DataFrame` формы `(4, 2)`. Внешние скобки выполняют операцию
выбора, внутренний список передаёт несколько названий столбцов.

## loc — выбор по меткам

Общий формат:

```python
readings.loc[метки_строк, метки_столбцов]
```

Одна ячейка:

```python
cnc_03_temperature = readings.loc[2, "temperature"]
```

Результат — `91.5`.

Диапазон меток и список столбцов:

```python
selected_machine_temperatures = readings.loc[
    1:3,
    ["machine_id", "temperature"],
]
```

У `loc` правая граница среза включается. Поэтому метки `1:3` означают строки
`1`, `2`, `3`, то есть `CNC-02`, `CNC-03`, `CNC-04`. Форма — `(3, 2)`.

## iloc — выбор по позициям

Общий формат:

```python
readings.iloc[позиции_строк, позиции_столбцов]
```

Выполнен выбор:

```python
selected_machine_rpm = readings.iloc[1:3, [0, 2]]
```

Строки на позициях `1` и `2` соответствуют `CNC-02` и `CNC-03`. Столбцы на
позициях `0` и `2` — `machine_id` и `rpm`. Форма — `(2, 2)`.

У `iloc` правая граница не включается, как в обычном Python-срезе.

## Метка не равна позиции

При стандартном `RangeIndex` метки `0, 1, 2, 3` совпадают с позициями, поэтому
различие может быть незаметно. После:

```python
readings_by_machine = readings.set_index("machine_id")
```

индексом становятся:

```text
CNC-01, CNC-02, CNC-03, CNC-04
```

`machine_id` перестаёт быть обычным столбцом. Теперь `loc["CNC-03"]` выбирает
строку по инженерной метке, а `iloc[2]` — третью строку по физической позиции.

Выбор по именам обычно надёжнее: перестановка столбцов меняет их позиции и может
сломать `iloc`, но не изменяет обращение к столбцу по стабильному имени.

## Почему одна строка стала Series

Выполнен выбор:

```python
cnc_03_by_machine = readings_by_machine.loc[
    "CNC-03",
    ["temperature", "rpm", "is_running"],
]
```

Одна метка строки является скалярным селектором, поэтому измерение строк
схлопывается. Результат:

```text
type  → pandas.Series
ndim  → 1
shape → (3,)
```

Вертикальный печатный вид не превращает объект в таблицу. Структуру определяют
через `type`, `ndim` и `shape`.

Если передать список из одной метки — `loc[["CNC-03"], ...]` — измерение строк
сохранится и результат будет `DataFrame` формы `(1, 3)`.

## Ошибки и причины

- Для `loc[1:3]` сначала ожидались только две строки. У `loc` правая метка
  включается, поэтому строк три.
- Формулировка «станки 1 и 2» смешивала позиции и идентификаторы. Позиции `1` и
  `2` соответствуют значениям `CNC-02` и `CNC-03`.
- Имя `machinine_id_and_rpm` содержало опечатку, которая ухудшала поддержку.
- Имена обычных переменных начинались с заглавных букв; приведены к `snake_case`.
- Слишком конкретное имя диапазона заменено переносимым
  `selected_machine_temperatures`.
- Печатный вид выбранной строки был принят за `DataFrame`; тип подтверждён
  программно.
- Многострочное выражение сначала имело неравномерные отступы; приведено к
  читаемому формату со скобками и завершающей запятой.

## Math Core

- `DataFrame` имеет две оси, `Series` — одну.
- Скалярный выбор одной строки уменьшает размерность с 2 до 1.
- Выбор списком из одной строки сохраняет двумерность.
- Срез `iloc[a:b]` соответствует полуоткрытому интервалу `[a, b)`, а срез
  `loc[a:b]` по существующим упорядоченным меткам включает обе границы.

## English Core

- **label** — метка;
- **position** — позиция;
- **row selection** — выбор строк;
- **column selection** — выбор столбцов;
- **slice** — срез;
- **inclusive boundary** — включённая граница;
- **exclusive boundary** — исключённая граница;
- **index** — индекс, набор меток строк;
- **scalar selector** — выбор одной меткой или одним значением;
- **dimensionality** — размерность.
