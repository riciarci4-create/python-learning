## Цель

Создавать числовые NumPy-массивы, читать их структуру, выбирать отдельные
элементы и столбцы и выполнять векторные операции без ручного цикла.

## Теория

`np.array()` создаёт `ndarray` — N-мерный массив. В отличие от универсального
Python-списка, NumPy-массив хранит данные общего `dtype` и предназначен для
массовых числовых операций.

```python
import numpy as np

spindle_speeds = np.array([1200, 1500, 1800])
```

`np` — общепринятый псевдоним (**alias**) модуля NumPy.

## Основные атрибуты

- `shape` — длины всех осей в виде кортежа;
- `ndim` — количество осей;
- `size` — общее число элементов;
- `dtype` — единый тип элементов.

Для массива `[1200, 1500, 1800]`:

```text
shape = (3,)
ndim = 1
size = 3
dtype = int64
```

`(3,)` — кортеж одной оси длиной 3. У одномерного массива нет отдельных строк
и столбцов. Форма `(1, 3)` уже означает двумерную матрицу из одной строки и
трёх столбцов.

## Двумерная инженерная матрица

```python
machine_data = np.array([
    [72, 1500, 8],
    [75, 1600, 9]
])
```

Здесь строки соответствуют машинам, а столбцы — температуре, оборотам и номеру
программы. Массив имеет `shape == (2, 3)`, `ndim == 2`, `size == 6`.

Форма описывает структуру, но физический смысл осей задаёт инженер или договор
о данных.

## Индексация

Для двумерного массива используется порядок:

```python
array[row_index, column_index]
```

Индексы начинаются с нуля:

- `machine_data[1, 1]` — обороты второй машины, `1600`;
- `machine_data[0, 2]` — программа первой машины, `8`.

## Срезы

Двоеточие означает «все элементы этой оси»:

```python
machine_data[:, 0]  # температуры всех машин
machine_data[:, 1]  # обороты всех машин
machine_data[0, :]  # все параметры первой машины
```

Выбор одного столбца возвращает одномерный массив. Для двух машин форма
результата равна `(2,)`.

## Векторизация

NumPy применяет арифметическую операцию сразу ко всем элементам:

```python
increased_speeds = spindle_speeds + 100
```

Результат равен `[1300, 1600, 1900]`, а исходный массив остаётся
`[1200, 1500, 1800]`. Обычное выражение создаёт новый результат; присваивание
обратно или операция на месте рассматривались бы отдельно.

## Инженерное задание

Из матрицы извлечён столбец температур `[72, 75]`. Для компенсации постоянной
погрешности датчика создан новый массив:

```python
calibrated_temperatures = temperatures + 2
```

Результат `[74, 77]`; исходные измерения сохранены для проверки и аудита.

## Приведение типа

NumPy стремится хранить общий `dtype`. Для массива `[72, 75.5]` выбирается
дробный тип, а `72` представляется как `72.0`. Смешение чисел и текста может
превратить весь массив в строки и сделать арифметику невозможной.

## Ошибки и корректировки

- `np` потребовал отдельного объяснения как псевдоним библиотеки.
- Одномерная форма `(3,)` сначала была названа строкой из трёх столбцов;
  уточнено отсутствие строк и столбцов у одной оси.
- При чтении индекса был выбран другой массив; после сверки координаты
  `row, column` применены правильно.
- Число `2` было названо формой; `shape` всегда возвращается кортежем `(2,)`.
- `.shape` сначала подписывался как длина; исправлено на форму массива.
- Один `print()` с двумя аргументами переносил код, но не вывод; применены два
  независимых вызова.

## Math Core

- Одномерный массив соответствует вектору.
- Двумерный массив соответствует прямоугольной матрице.
- Для формы `(rows, columns)` число элементов равно `rows * columns`.
- Индекс — дискретная координата на соответствующей оси.
- Векторная операция применяет одно отображение ко всем компонентам.

## English Core

- **array** — массив;
- **ndarray** — N-мерный массив NumPy;
- **shape** — форма;
- **dimension** — измерение;
- **axis** — ось;
- **data type / dtype** — тип данных элементов;
- **indexing** — индексация;
- **slice / slicing** — срез / получение среза;
- **vectorization** — векторизация.
