## Основная теория

### Что означает `axis`

Для двумерной матрицы существуют две оси:

- `axis=0` — ось строк;
- `axis=1` — ось столбцов.

При агрегировании указанная ось схлопывается, а остальные размеры сохраняются.

Для матрицы формы `(4, 3)`:

- агрегирование по `axis=0` схлопывает 4 строки и возвращает 3 результата;
- агрегирование по `axis=1` схлопывает 3 столбца и возвращает 4 результата.

### Агрегирование без оси

Сигнатура на текущем уровне:

```python
array.mean(axis=None)
```

При `axis=None` метод использует все элементы массива и возвращает один
показатель.

### Среднее по строкам

Для последовательных измерений двух станков:

```python
measurements = np.array([
    [70, 72, 74],
    [80, 82, 84]
])
```

выражение:

```python
measurements.mean(axis=1)
```

возвращает:

```text
[72.0, 82.0]
```

Это средняя температура каждого станка. Результат имеет два элемента, потому
что после схлопывания столбцов остаются две строки.

### Среднее по столбцам

Выражение:

```python
measurements.mean(axis=0)
```

возвращает:

```text
[75.0, 77.0, 79.0]
```

Это среднее каждого момента измерения по двум станкам. После схлопывания строк
остаются три столбца.

### Другие агрегаты

Параметр `axis` аналогично работает с:

```python
array.min(axis=...)
array.max(axis=...)
array.sum(axis=...)
```

`measurements.max(axis=1)` вернул `[74, 84]` — пиковую температуру каждого
станка.

### Единый `dtype`

Матрица:

```python
machine_metrics = np.array([
    [72, 1500, 2.1],
    [80, 1700, 3.5],
    [76, 1600, 2.8]
])
```

получает единый тип `float`, потому что массив NumPy должен иметь общий
`dtype`. `float` способен представить как дробные значения, так и целые в виде
`72.0` и `1500.0`; преобразование к `int` потеряло бы дробную часть.

### Физический смысл оси

Столбцы матрицы `machine_metrics` содержат температуру, обороты и вибрацию.
Среднее по `axis=0` имеет смысл, потому что каждый столбец агрегируется отдельно:

```text
[76.0, 1600.0, 2.8]
```

Среднее по `axis=1` математически допустимо, но физически бессмысленно: внутри
строки смешались бы градусы, обороты и вибрация.

### Размах показателей

Размах вычисляется как:

```text
range = maximum - minimum
```

Для каждого столбца применено векторное выражение:

```python
machine_metrics.max(axis=0) - machine_metrics.min(axis=0)
```

Результат:

```text
[8.0, 200.0, 1.4]
```

### Ошибка выбора оси

У двумерного массива допустимы только оси `0` и `1`. Попытка использовать
`axis=2` приводит к `AxisError`. Перед выбором оси нужно проверять:

- `ndim` — количество осей;
- `shape` — длину каждой оси.

3. Вычислены средние значения каждого замера через `axis=0`.
4. Найдена пиковая температура каждого станка.

## Исправленные неточности

- В строке массива отсутствовал пробел после запятой; форматирование приведено
  к PEP 8.
- Именованный аргумент был записан как `axis = 1`. Уточнено: внутри вызова
  функции используется `axis=1`, без пробелов вокруг `=`.
- Уточнено, почему `.mean()` возвращает `float`: результат деления может быть
  дробным.
- Правило `axis` закреплено через схлопывание измерения, а не механическое
  запоминание направления.

## Math Core

- Матрица формы `(rows, columns)` хранит наблюдения и признаки или серии
  измерений.
- Агрегирование уменьшает размерность: матрица превращается в вектор.
- Среднее описывает центральное значение набора.
- Размах `max - min` описывает ширину наблюдаемого диапазона, но чувствителен
  к выбросам.
- Нельзя складывать и усреднять величины с разными единицами без осмысленного
  преобразования.

## English Core

- **axis** — ось массива;
- **row-wise** — по строкам;
- **column-wise** — по столбцам;
- **reduction** — свёртка, уменьшение размерности агрегированием;
- **range** — размах между максимумом и минимумом.
